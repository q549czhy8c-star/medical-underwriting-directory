# Public Sources

The seed dataset uses public sources only for general medical risk context.

- CDC Heart Disease Risk Factors: https://www.cdc.gov/heart-disease/risk-factors/index.html
- NICE Hypertension in Adults NG136: https://www.nice.org.uk/guidance/ng136/chapter/recommendations
- WHO Diabetes Fact Sheet: https://www.who.int/news-room/fact-sheets/detail/diabetes
- CDC Asthma: https://www.cdc.gov/asthma/index.html
- American Cancer Society Cancer Recurrence: https://www.cancer.org/cancer/survivorship/long-term-health-concerns/recurrence.html

These sources do not replace reinsurer manuals. They only support public risk concern wording.
